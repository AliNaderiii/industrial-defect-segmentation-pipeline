# Archived v1 visual artifacts

These are genuine visual artifacts retained from the repository before the v2 split-integrity revision. They are historical/qualitative evidence only.

- Their numbers were obtained before the official test set was reserved from selection, so they are not independent v2 test results.
- They must not be quoted as the current v2 benchmark or compared with future v2 runs.
- New reportable visuals are generated only from a recorded v2 run using `src.reporting`.
